# Workshop 1: Foundations of Data Science, Wrangling and Plotting

 Set up a version controlled R project workflow, including cloning a class repository, detaching it from the original remote, and pushing an independent
 copy to my own GitHub profile. Learned to organise a project into clear subfolders for raw data, code, outputs and documentation, supported by a .gitignore file and a descriptive README.
 Developed core tidyverse skills for filtering, grouping and summarising biological data using the Palmer Penguins dataset, and built foundational ggplot2 visualisations to explore morphological differences between species. 
 This workshop was completed without AI assistance to build direct, hands on understanding of how R processes data and how to diagnose errors independently.

# Workshop 2: Advanced Data Wrangling, Extracting Ecological Signals from Noisy Systems

 Learned the principles of tidy data, including the rule that each variable should have its own column, each observation its own row, and each value its own cell, and understood why this structure is essential for working effectively with the tidyverse. Gained experience reshaping data frames between wide and long formats, and used mutating joins to merge biological datasets with spatial and temporal metadata. Also worked with stringr and lubridate to resolve string mismatches and date time formatting issues common in real ecological data. This workshop introduced AI assisted coding as an optional tool, while emphasising the responsibility to critically evaluate and understand any AI generated code before relying on it.

 # Workshop 3: Plot Deconstruction

 Developed critical evaluation skills for scientific data visualisation by deconstructing an existing published figure and identifying weaknesses in its design, including colour choice, axis scaling and labelling. Learned to rebuild a clearer, more communicative version of the figure using ggplot2, including reshaping data with pivot_longer, applying considered colour palettes, and using annotation to highlight key trends. Gained a deeper understanding that effective data visualisation requires deliberate design choices that anticipate how an audience interprets a figure, not just accurate representation of the underlying data.

# Workshop 4: Spatial Mapping

 Learned to work with spatial vector data in R using the sf package, including handling coordinate reference systems and performing spatial joins between point and polygon data. Gained experience building publication quality maps using ggplot2's geom_sf(), layering coastline and continental shelf polygons beneath species richness data. Understood the importance of colour scale choice when visualising continuous spatial data, and developed an appreciation for how spatial context adds interpretive value to ecological data compared with non spatial analysis alone.
